# K2EXEmail

K2EXEmail is an open-source, cross-platform Winlink email client built with Go and Fyne.

The goal is to provide a modern desktop email experience for Winlink while supporting Internet, AREDN, and amateur-radio communication paths.

## Status

Early development.

## Platforms

- Windows
- Linux
- macOS

## Development

Requires Go 1.24 or later.

Run:

go run ./cmd/k2exemail

Test:

go test ./...
go vet ./...
